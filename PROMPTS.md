# Invios — Full Client-Workflow OS: Claude Design Build Prompts

12 detailed, self-contained build prompts covering every screen of the full client-workflow OS (Dashboard, Invoices, Quotations, Clients, Settings, Auth, plus the new Proposals/E-Signature, Time Tracking, Projects & Tasks, Project Pages, and Command Palette modules), all built against the [Linear Design System](./DESIGN.md).

## How to use these

1. Finish the "Set up your design system" form in Claude Design first — company name/blurb, the `linear-design-system` GitHub link, and the font files, per the setup answers already given.
2. Paste ONE prompt at a time into the chat, in the order below. Each is fully self-contained — it re-states the relevant design tokens and realistic content itself, so it doesn't depend on the others being pasted first, but building in this order matches how the features actually depend on each other product-wise (e.g. Time Tracking's "convert to invoice" flow assumes the Invoices editor already exists).
3. Each prompt was generated, adversarially critiqued against `DESIGN.md`, and fixed in a review pass; a final cross-module consistency scan found no drift across all 12 (same client names, invoice/quote/proposal numbering, and design tokens used identically everywhere they overlap).
4. Content bible used throughout, for reference: product name Invios, six recurring clients (Nour Al Fahad Trading LLC, Meridian Studio FZ, Castle Peak Retail, Halcyon Media Group, Bright Path Consulting, Ferrous & Oak Interiors), three team members (Sami Haddad/owner, Layla Nasser/designer, Omar Khalil/developer), "today" anchored to July 13, 2026.
